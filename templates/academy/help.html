01 · CHECK FIRST

Is Python already installed?

Python is the program that reads and runs your .py files. A terminal is the app where you type commands. Type a command below and press Enter; do not type a $, > or >>> prompt in front of it.

Windows

Open Start, search for PowerShell or Terminal, and open it.

py --version

If py is unavailable, try:

python --version

macOS / Linux

On macOS use Spotlight → Terminal. On Ubuntu open Terminal, or press Ctrl + Alt + T.

python3 --version

A result such as Python 3.12.14 means Python is available. The numbers are the major, minor and patch version. These lessons target Python 3.12; a newer stable Python 3 version also handles these basic programs. If the command fails, use your installation steps below.

02 · WINDOWS

Install Python on Windows

  1. Open the official Python Windows downloads page ↗. Download and install the Python install manager.
  2. Close and reopen PowerShell or Windows Terminal so it picks up the new commands.
  3. Install a Python 3.12 runtime to match this course:
    py install 3.12

    This command is for the new install manager. If you already have the older Python launcher and py --version works, you can use your existing supported Python instead.

  4. Check your installed version:
    py --version

    If more than one version is installed, check the course version specifically with py -3.12 --version.

Using a traditional Python installer instead? Enable Add python.exe to PATH when that option is offered. Reopen the terminal afterwards. PATH is the list of folders Windows searches for commands.

Official reference: Using Python on Windows.

03 · macOS

Install Python on a Mac

  1. Open the official Python macOS downloads page ↗ and select a supported stable Python 3 release with a macOS installer.
  2. Download the .pkg installer, open it, and follow the installer steps.
  3. Open a new Terminal window and check:
    python3 --version

Use python3 for the examples below. Keep Apple's system-provided Python in place; installing your own Python does not require removing it.

Official reference: Using Python on macOS.

04 · LINUX

Install Python on Ubuntu / Debian

Most Linux distributions already include Python 3. Check with python3 --version first. On Ubuntu / Debian, these commands install the interpreter, virtual-environment support and package tools from the distribution:

sudo apt update
sudo apt install python3 python3-venv python3-pip
python3 --version

Run one line at a time. sudo requests administrator permission and may ask for your computer password. Nothing appears while typing that password; this is normal. The available Python version depends on your Linux release. Other distributions use different package managers—follow their official instructions.

Do not remove or replace Linux's system Python. You do not need sudo to run your own practice programs.

Official reference: Python setup on Ubuntu.

05 · YOUR FIRST LOCAL PROGRAM

Create a file. Run it. Change it.

  1. Create a folder named python-practice somewhere easy to find, such as your Documents folder.
  2. Open a plain-text/code editor, such as IDLE installed with Python, or an editor you already use. Create a new file containing:
    name = input("What is your name? ")
print(f"Hello, {name}! You are running Python.")
  3. Save it in your practice folder as hello.py. Use plain text, not a Word document. If using Notepad, choose Save as type: All files and make sure the name is not hello.py.txt.
  4. Open a terminal in that folder. On Windows, open the folder in File Explorer and choose Open in Terminal if available. On any system, you can type cd followed by the folder's full path in quotes:
    cd "C:\Users\YourName\Documents\python-practice"

    That is a Windows example. A macOS example is cd "/Users/YourName/Documents/python-practice"; on Linux use your actual home path, for example cd "/home/yourname/Documents/python-practice". Replace the example username with your own.

  5. Run the file using the command for your system:

    Windows

    py hello.py

    If you verified python instead of py, use python hello.py.

    macOS / Linux

    python3 hello.py
  6. When the program asks for your name, type it and press Enter. You should see a greeting. Change the greeting in the editor, save the file, then rerun the command.
Your first success check

You can show the version, run hello.py, answer its input prompt, and change its output. You are ready for the terminal missions.

The browser challenges expect exact output, so omit friendly input prompts there when the challenge says so. Local programs can use prompts to help the person running them.

Try Python without a file

Run py on Windows, or python3 on macOS/Linux. You will see the Python prompt >>>. Enter:

print("Hello from Python")
2 + 3

You should see a message and 5. Type exit() to return to the terminal. Commands such as cd and python3 hello.py belong in the terminal, not after >>>.

08 · WHEN SOMETHING GOES WRONG

Basic troubleshooting

“Python is not recognized” / “command not found” +

Close and reopen your terminal after installation. On Windows try py --version and python --version. On macOS/Linux use python3 --version. If none works, revisit your system's installation steps. On a work computer, ask IT for help if software installation is restricted.

Windows opens the Microsoft Store instead of Python +

Try py --version. If that works, use py to run your files. Otherwise finish installing Python from the official source, reopen the terminal, and consult the Windows Python troubleshooting link above for install-manager and app-execution-alias settings.

“Can't open file” / “No such file or directory” +

Check the current folder with pwd and list files with dir or ls. Move to the folder containing your file. Verify the spelling and extension, including whether the file accidentally ends in .py.txt. Quote the filename or full path if it contains spaces.

I see >>> and terminal commands give SyntaxError +

You are inside Python's interactive prompt. Type exit(), press Enter, then run your terminal command. Do not copy the >>> characters into your program.

The program appears to be stuck +

It may be waiting at input(): type the requested value and press Enter. If it is looping indefinitely, press Ctrl + C. In the website editor, use Stop.

SyntaxError, IndentationError or ValueError +

Read the last line of the error message, then look for the named line in your own file. Check matching quotes and parentheses for SyntaxError. Use consistent four-space blocks for IndentationError. For ValueError, check that text can be converted to the requested number. An error is feedback about a specific instruction, not a failed learning attempt.

My changes do not appear +

Save your file before running it again. Check that you edited the same file you are running, and that the terminal is in the right folder.

Do I need pip, a virtual environment, or Django now? +

No. The first ten downloaded programs use only Python's built-in features. Later lessons will explain packages, pip, isolated project environments and Django step by step. A version check for pip, when you reach that stage, is py -m pip --version on Windows or python3 -m pip --version on macOS/Linux. Do not use sudo pip install to change system Python.
